## X-Clone (Twitter UI Clone)

A fully responsive and modern X (Twitter) UI clone built with HTML, Tailwind CSS, and JavaScript.
This project focuses on clean UI design, smooth responsiveness, and interactive frontend behavior.

> ⚠️ This is a frontend-only UI clone created for learning and portfolio purposes.
> It does not use real X/Twitter APIs or backend services.

---

## 🌐 Live Demo

(https://x-cloane.netlify.app)

---

## 🚀 Key Highlights

- Fully responsive across desktop, tablet, and mobile
- Clean dark theme inspired by X (Twitter)
- Sidebar, feed, and right panel layout
- AI-generated image refresh on reload
- Fast and lightweight frontend project

---

## ✨ Features

- Modern X-style UI
- Responsive layout using Tailwind CSS
- Dynamic image refresh using JavaScript
- Clean and readable component layout
- Optimized spacing and typography

---

## 🛠 Tech Stack

- HTML5
- Tailwind CSS
- CSS
- Vanilla JavaScript

No backend, no database, no authentication.
